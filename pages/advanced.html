🎨 Canvas API

Canvas element JavaScript দিয়ে 2D graphics আঁকতে দেয়। Games, charts, animations তৈরিতে ব্যবহৃত হয়।

HTML 
<canvas id="myCanvas" width="400" height="300">
  Canvas সাপোর্ট করে না
</canvas>

<script>
  // Canvas context নিন
  const canvas = document.getElementById('myCanvas');
  const ctx = canvas.getContext('2d');

  // Rectangle আঁকুন
  ctx.fillStyle = '#6366f1';
  ctx.fillRect(50, 50, 150, 100);

  // Circle আঁকুন
  ctx.beginPath();
  ctx.arc(300, 100, 50, 0, Math.PI * 2);
  ctx.fillStyle = '#06b6d4';
  ctx.fill();

  // Line আঁকুন
  ctx.beginPath();
  ctx.moveTo(50, 200);
  ctx.lineTo(350, 200);
  ctx.strokeStyle = '#f472b6';
  ctx.lineWidth = 3;
  ctx.stroke();
</script>

🔷 SVG Graphics

SVG (Scalable Vector Graphics) XML-based vector image format। যেকোনো size এ sharp থাকে।

HTML 
<svg width="200" height="200" viewBox="0 0 200 200">
  <!-- Rectangle -->
  <rect x="10" y="10" width="80" height="60" 
        fill="#6366f1" rx="8"/>

  <!-- Circle -->
  <circle cx="150" cy="50" r="40" fill="#06b6d4"/>

  <!-- Line -->
  <line x1="10" y1="150" x2="190" y2="150" 
        stroke="#f472b6" stroke-width="3"/>

  <!-- Text -->
  <text x="100" y="180" text-anchor="middle" 
        fill="#f8fafc">SVG Text</text>
</svg>

Canvas vs SVG:

বিষয় Canvas SVG
Type Raster (Pixel-based) Vector
Scaling Pixelated হয়ে যায় সব size এ sharp
Use Case Games, complex animations Icons, logos, diagrams
DOM Access নেই প্রতিটি element DOM এ আছে

📍 Geolocation API

ব্যবহারকারীর location জানতে পারেন। Maps, weather apps এ ব্যবহৃত হয়।

⚠️

Permission Required

ব্যবহারকারীকে অবশ্যই permission দিতে হবে। HTTPS এ কাজ করে।

JavaScript 
// Check if supported
if ('geolocation' in navigator) {
  
  navigator.geolocation.getCurrentPosition(
    // Success callback
    function(position) {
      const lat = position.coords.latitude;
      const lng = position.coords.longitude;
      const accuracy = position.coords.accuracy;
      
      console.log(`Latitude: ${lat}`);
      console.log(`Longitude: ${lng}`);
      console.log(`Accuracy: ${accuracy} meters`);
    },
    // Error callback
    function(error) {
      console.error('Error:', error.message);
    },
    // Options
    {
      enableHighAccuracy: true,
      timeout: 10000,
      maximumAge: 0
    }
  );
}

💾 Web Storage API

Browser এ data store করুন। Cookies এর চেয়ে সহজ এবং বেশি storage।

localStorage

Permanent storage। Browser বন্ধ করলেও data থাকে। ~5MB limit।

sessionStorage

Tab/Session specific। Tab বন্ধ করলে data মুছে যায়।

JavaScript 
// Store data
localStorage.setItem('username', 'রহিম');
localStorage.setItem('settings', JSON.stringify({theme: 'dark'}));

// Retrieve data
const name = localStorage.getItem('username');
const settings = JSON.parse(localStorage.getItem('settings'));

// Remove single item
localStorage.removeItem('username');

// Clear all
localStorage.clear();

// Check length
console.log(localStorage.length);

🖱️ Drag & Drop API

Native drag and drop functionality। File upload, list reordering এ ব্যবহৃত হয়।

HTML + JavaScript 
<!-- Draggable element -->
<div draggable="true" id="dragItem">Drag me!</div>

<!-- Drop zone -->
<div id="dropZone">Drop here</div>

<script>
const item = document.getElementById('dragItem');
const zone = document.getElementById('dropZone');

item.addEventListener('dragstart', (e) => {
  e.dataTransfer.setData('text/plain', e.target.id);
});

zone.addEventListener('dragover', (e) => {
  e.preventDefault(); // Allow drop
});

zone.addEventListener('drop', (e) => {
  e.preventDefault();
  const id = e.dataTransfer.getData('text/plain');
  zone.appendChild(document.getElementById(id));
});
</script>
