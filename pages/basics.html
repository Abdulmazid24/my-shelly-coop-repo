🌟 HTML কি?

HTML (HyperText Markup Language) হলো ওয়েব পেজ তৈরির মূল ভাষা। এটি কোনো প্রোগ্রামিং ভাষা নয়, বরং একটি markup language যা ওয়েব ব্রাউজারকে বলে দেয় কীভাবে content প্রদর্শন করতে হবে।

💡

জানা ভালো

HTML5 হলো HTML এর সর্বশেষ version (2014 সালে প্রকাশিত)। এতে audio, video, canvas সহ অনেক নতুন features যোগ হয়েছে।

HTML এর ইতিহাস

  • 1991: Tim Berners-Lee HTML তৈরি করেন
  • 1995: HTML 2.0 প্রকাশিত
  • 1997: HTML 3.2 এবং HTML 4.0
  • 2014: HTML5 officially recommended
  • 2017: HTML 5.2 (সর্বশেষ version)

🚀 প্রথম HTML পেজ

চলুন আপনার প্রথম HTML পেজ তৈরি করি! একটি text editor (যেমন VS Code, Notepad++) খুলে নিচের কোড লিখুন:

HTML 
<!DOCTYPE html>
<html>
  <head>
    <title>আমার প্রথম ওয়েবসাইট</title>
  </head>
  <body>
    <h1>Hello World! 🎉</h1>
    <p>এটি আমার প্রথম ওয়েব পেজ।</p>
  </body>
</html>
✅

চেষ্টা করুন!

ফাইলটি index.html নামে save করুন এবং ব্রাউজারে খুলুন।

📄 Document Structure

প্রতিটি HTML5 document এই মৌলিক structure অনুসরণ করে:

HTML 
<!-- DOCTYPE declaration - HTML5 ব্যবহার করছি -->
<!DOCTYPE html>

<!-- Root element - সবকিছু এর ভিতরে থাকে -->
<html lang="bn">

  <!-- Head section - metadata থাকে -->
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>পেজ টাইটেল</title>
  </head>

  <!-- Body section - visible content থাকে -->
  <body>
    <!-- আপনার content এখানে -->
  </body>

</html>

প্রতিটি অংশের ব্যাখ্যা:

<!DOCTYPE html>

ব্রাউজারকে বলে এটি HTML5 document। এটি ছাড়া browser "quirks mode" এ চলতে পারে।

<html>

Root element - পুরো document এর container। lang attribute ভাষা নির্দেশ করে।

<head>

Metadata container - title, charset, stylesheets, scripts ইত্যাদি থাকে। পেজে দেখা যায় না।

<body>

পেজের সব visible content এখানে থাকে - text, images, links, forms ইত্যাদি।

🏷️ Elements & Tags

HTML elements হলো HTML পেজের building blocks। প্রতিটি element tags দিয়ে তৈরি।

Element এর গঠন
<p>Hello World</p>
↑ Opening Tag ↑ Content ↑ Closing Tag

Tag এর প্রকারভেদ:

প্রকার উদাহরণ বিবরণ
Container Tags <p>...</p> Opening এবং closing tag দুটোই থাকে
Empty/Void Tags <br>, <img> শুধু opening tag, কোনো content নেই
⚠️

গুরুত্বপূর্ণ!

HTML tags case-insensitive, কিন্তু lowercase ব্যবহার করা best practice।

⚙️ Attributes

Attributes elements এ additional information যোগ করে। Opening tag এর ভিতরে থাকে।

HTML 
<!-- Syntax: attribute="value" -->
<a href="https://example.com" target="_blank">Visit</a>

<img src="photo.jpg" alt="My Photo" width="300">

<input type="text" id="name" class="input-field" required>

সাধারণ Global Attributes:

id

Unique identifier - প্রতি পেজে একবারই ব্যবহার করা যায়

class

CSS styling এর জন্য - একাধিক element এ ব্যবহার করা যায়

style

Inline CSS styles - সরাসরি element এ style দেওয়া

title

Tooltip text - hover করলে দেখা যায়

📝 Headings (শিরোনাম)

HTML এ ৬ লেভেলের heading আছে - <h1> (সবচেয়ে বড়) থেকে <h6> (সবচেয়ে ছোট)।

Live Preview

H1 - প্রধান শিরোনাম

H2 - উপ শিরোনাম

H3 - সেকশন শিরোনাম

H4 - সাব-সেকশন

H5 - ছোট শিরোনাম
H6 - সবচেয়ে ছোট
🎯

SEO Tips

প্রতি পেজে একটি <h1> ব্যবহার করুন। Headings ক্রমানুসারে রাখুন (h1 → h2 → h3)।

📄 Paragraphs

<p> tag দিয়ে paragraph তৈরি করা হয়। Browser automatically উপরে ও নিচে margin যোগ করে।

HTML 
<p>এটি প্রথম paragraph। HTML এ space এবং line breaks 
   collapse হয়ে যায়।</p>

<p>এটি দ্বিতীয় paragraph।<br>
এখানে line break আছে।</p>

<hr> <!-- Horizontal Rule -->

<p>এটি তৃতীয় paragraph।</p>

✨ Text Formatting

HTML এ বিভিন্ন text formatting tags আছে:

Tag উদ্দেশ্য Output
<strong> গুরুত্বপূর্ণ text (bold) Bold Text
<em> Emphasis (italic) Italic Text
<mark> Highlighted text Highlighted
<del> Deleted text Deleted
<ins> Inserted text Inserted
<sub> Subscript H2O
<sup> Superscript X2
<code> Code text console.log()

🔗 Links (হাইপারলিংক)

<a> (anchor) tag দিয়ে links তৈরি করা হয়। href attribute এ URL থাকে।

HTML 
<!-- External Link -->
<a href="https://google.com">Google এ যান</a>

<!-- New Tab এ Open -->
<a href="https://google.com" target="_blank">New Tab</a>

<!-- Internal Page Link -->
<a href="about.html">About Page</a>

<!-- Same Page Section (Anchor) -->
<a href="#contact">Contact Section এ যান</a>

<!-- Email Link -->
<a href="mailto:info@example.com">Email করুন</a>

<!-- Phone Link -->
<a href="tel:+8801234567890">Call করুন</a>

🖼️ Images

<img> tag দিয়ে image যোগ করা হয়। এটি একটি void element - কোনো closing tag নেই।

HTML 
<!-- Basic Image -->
<img src="photo.jpg" alt="ফটো বর্ণনা">

<!-- With Dimensions -->
<img src="logo.png" alt="Logo" width="200" height="100">

<!-- From URL -->
<img src="https://example.com/image.jpg" alt="External Image">

alt attribute বাধ্যতামূলক! এটি accessibility এবং SEO এর জন্য অত্যন্ত গুরুত্বপূর্ণ।
