🧩 Web Components

Web Components হলো reusable, encapsulated HTML elements তৈরির platform। তিনটি মূল technology নিয়ে গঠিত:

1. Custom Elements

নিজের HTML tag তৈরি করুন যেমন <my-button>

2. Shadow DOM

Encapsulated DOM এবং styling - বাইরের CSS affect করে না

3. HTML Templates

<template> এবং <slot> দিয়ে reusable markup

✅

কেন Web Components?

Framework ছাড়াই reusable components তৈরি করুন। React, Vue, Angular সবার সাথে কাজ করে!

🏷️ Custom Elements

নিজের HTML element class তৈরি করে browser এ register করুন।

JavaScript 
// Custom Element Class
class MyGreeting extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
  }

  // Called when element added to DOM
  connectedCallback() {
    const name = this.getAttribute('name') || 'World';
    this.shadowRoot.innerHTML = `
      
      

        
Hello, ${name}! 👋

      

    `;
  }

  // Watch for attribute changes
  static get observedAttributes() {
    return ['name'];
  }

  attributeChangedCallback(name, oldVal, newVal) {
    if (oldVal !== newVal) {
      this.connectedCallback();
    }
  }
}

// Register the element
customElements.define('my-greeting', MyGreeting);
HTML Usage 
<!-- Custom element ব্যবহার -->
<my-greeting name="রহিম"></my-greeting>
<my-greeting name="করিম"></my-greeting>
⚠️

Naming Convention

Custom element নামে অবশ্যই hyphen (-) থাকতে হবে। যেমন: my-element, user-card

👻 Shadow DOM

Shadow DOM encapsulated DOM tree তৈরি করে। Component এর CSS বাইরে leak হয় না।

JavaScript 
const host = document.getElementById('myHost');

// Create Shadow Root
const shadow = host.attachShadow({ mode: 'open' });
// mode: 'open' - JavaScript দিয়ে access করা যায়
// mode: 'closed' - Access করা যায় না

// Shadow DOM এ content যোগ করুন
shadow.innerHTML = `
  
  
Shadow DOM Content!

`;

// Access shadow root (if open)
console.log(host.shadowRoot); // Shadow DOM

Shadow DOM vs Light DOM:

বিষয় Light DOM Shadow DOM
CSS Global, সব জায়গায় effect করে Encapsulated, শুধু shadow এ
Access document.querySelector() element.shadowRoot
Styling বাইরের CSS দিয়ে style হয় CSS Variables দিয়ে customize

📋 Templates & Slots

<template> reusable markup, <slot> content projection এর জন্য।

HTML 
<!-- Template define করুন -->
<template id="card-template">
  <style>
    .card { padding: 1rem; border: 1px solid #ccc; }
    .card-header { font-weight: bold; }
  </style>
  <div class="card">
    <div class="card-header">
      <slot name="title">Default Title</slot>
    </div>
    <div class="card-body">
      <slot>Default content</slot>
    </div>
  </div>
</template>

<!-- Custom element এ ব্যবহার -->
<my-card>
  <span slot="title">Custom Title</span>
  <p>This is the card content.</p>
</my-card>

⚙️ Service Workers

Service Workers browser এ background script চালায়। Offline support এবং PWA এর জন্য essential।

💡

PWA (Progressive Web App)

Service Worker + Manifest = ওয়েবসাইট native app এর মতো কাজ করে, offline support সহ!

JavaScript - Registration 
// main.js - Register service worker
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/sw.js')
    .then(registration => {
      console.log('SW registered:', registration.scope);
    })
    .catch(error => {
      console.error('SW registration failed:', error);
    });
}
JavaScript - sw.js 
const CACHE_NAME = 'v1';
const urlsToCache = ['/', '/styles/main.css', '/js/app.js'];

// Install event - cache files
self.addEventListener('install', event => {
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then(cache => cache.addAll(urlsToCache))
  );
});

// Fetch event - serve from cache
self.addEventListener('fetch', event => {
  event.respondWith(
    caches.match(event.request)
      .then(response => response || fetch(event.request))
  );
});

🔧 Web Workers

Heavy computation background thread এ চালান। Main thread block হয় না, UI smooth থাকে।

JavaScript - Main Thread 
// Create worker
const worker = new Worker('worker.js');

// Send message to worker
worker.postMessage({ numbers: [1, 2, 3, 4, 5] });

// Receive result
worker.onmessage = function(e) {
  console.log('Sum:', e.data.sum);
};

// Handle errors
worker.onerror = function(e) {
  console.error('Worker error:', e.message);
};
JavaScript - worker.js 
// Receive message from main thread
self.onmessage = function(e) {
  const numbers = e.data.numbers;
  const sum = numbers.reduce((a, b) => a + b, 0);
  
  // Send result back
  self.postMessage({ sum: sum });
};

♿ WCAG Accessibility

WCAG (Web Content Accessibility Guidelines) সব ব্যবহারকারীর জন্য accessible website তৈরির standard।

ARIA (Accessible Rich Internet Applications)

HTML 
<!-- ARIA Roles -->
<div role="navigation" aria-label="Main Menu">...</div>
<div role="alert">Important message</div>

<!-- ARIA States -->
<button aria-expanded="false">Menu</button>
<input aria-invalid="true" aria-describedby="error-msg">

<!-- Skip Links -->
<a href="#main-content" class="skip-link">
  Skip to main content
</a>

<!-- Focus Management -->
<div tabindex="0">Focusable div</div>
<div tabindex="-1">Programmatically focusable</div>

Accessibility Checklist:

  • ✅ সব images এ meaningful alt text
  • ✅ Proper heading hierarchy (h1 → h2 → h3)
  • ✅ Sufficient color contrast (4.5:1 ratio)
  • ✅ Keyboard navigation সাপোর্ট
  • ✅ Form inputs এ <label> যুক্ত
  • ✅ Focus states visible
  • ✅ Skip navigation link
  • ✅ Error messages clear ও descriptive
