📝 HTML Forms

Forms ব্যবহারকারীর কাছ থেকে data সংগ্রহ করতে ব্যবহৃত হয়। Login, Registration, Contact forms সব form দিয়ে তৈরি।

HTML 
<form action="/submit" method="POST">
  <label for="name">নাম:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">ইমেইল:</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">জমা দিন</button>
</form>

Mobile Tip

সঠিক input type ব্যবহার করলে mobile এ সঠিক keyboard দেখায় (email এ @, number এ numpad)।

✅ HTML5 Form Validation

HTML5 built-in validation attributes দিয়ে JavaScript ছাড়াই form validate করা যায়।

HTML 
<!-- Required field -->
<input type="text" required>

<!-- Min/Max length -->
<input type="text" minlength="3" maxlength="20">

<!-- Pattern (Regex) -->
<input type="text" pattern="[A-Za-z]+" title="শুধু অক্ষর">

<!-- Number range -->
<input type="number" min="1" max="100">

<!-- Placeholder text -->
<input type="text" placeholder="আপনার নাম লিখুন">

📋 Lists

HTML এ তিন ধরনের list আছে: Ordered, Unordered এবং Description List।

  • Item Three

Ordered List <ol>

  2. Second Step
  3. Third Step

📊 Tables

Tables structured data প্রদর্শনের জন্য ব্যবহৃত হয়। Row এবং column এ data সাজানো হয়।

HTML 
<table>
  <thead>
    <tr>
      <th>নাম</th>
      <th>বয়স</th>
      <th>শহর</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>রহিম</td>
      <td>২৫</td>
      <td>ঢাকা</td>
    </tr>
    <tr>
      <td>করিম</td>
      <td>৩০</td>
      <td>চট্টগ্রাম</td>
    </tr>
  </tbody>
</table>

🏗️ Semantic HTML5

Semantic elements content এর অর্থ বোঝায়। SEO এবং Accessibility এর জন্য গুরুত্বপূর্ণ।

<header>

পেজ বা সেকশনের header - logo, navigation ইত্যাদি

<nav>

Navigation links এর জন্য

<main>

পেজের main content (একটিই থাকা উচিত)

<article>

স্বতন্ত্র content যেমন blog post, news article

<section>

Content এর thematic grouping

<aside>

পার্শ্ব content যেমন sidebar

<footer>

পেজ বা সেকশনের footer

<figure> / <figcaption>

Image/diagram with caption

🎬 Audio & Video

HTML5 এ native audio এবং video support আছে। আর Flash লাগে না!

HTML 
<!-- Video Element -->
<video controls width="640" poster="thumbnail.jpg">
  <source src="video.mp4" type="video/mp4">
  <source src="video.webm" type="video/webm">
  আপনার browser video support করে না।
</video>

<!-- Audio Element -->
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  <source src="audio.ogg" type="audio/ogg">
</audio>

Video Attributes:

  • controls - Play, pause, volume controls দেখায়
  • autoplay - Automatically চালু হয়
  • muted - Sound off
  • loop - Repeat হতে থাকে
  • poster - Thumbnail image
