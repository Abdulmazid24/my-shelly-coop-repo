# 🚀 HTML5 মাস্টারক্লাস

A modern, comprehensive HTML5 learning platform in Bengali (বাংলা) - from basics to PhD-level advanced topics.

## ✨ Features

- 📚 **Complete Curriculum** - Basic to PhD-level HTML5 tutorials
- 🎨 **Modern UI** - Glassmorphism, animations, dark/light themes
- 📱 **Responsive** - Works on all devices
- 🎮 **Interactive Playground** - Live code editor with real-time preview
- 🇧🇩 **Bengali Language** - বাংলায় সম্পূর্ণ টিউটোরিয়াল

## 📖 Learning Modules

| Level | Topics |
|-------|--------|
| **বেসিক** | Document structure, Elements, Attributes, Text formatting, Links, Images |
| **ইন্টারমিডিয়েট** | Forms, Input types, Tables, Lists, Semantic HTML, Audio/Video |
| **অ্যাডভান্সড** | Canvas, SVG, Geolocation, Web Storage, Drag & Drop |
| **PhD লেভেল** | Web Components, Shadow DOM, Service Workers, Web Workers, WCAG |

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- No frameworks - Pure frontend

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/Abdulmazid24/my-shelly-coop-repo.git
```

2. Open `index.html` in your browser

3. Start learning! 🎉

## 📂 Project Structure

```
my-shelly-coop-repo/
├── index.html          # Homepage
├── styles/
│   ├── main.css        # Core styles & design system
│   ├── components.css  # Reusable UI components
│   └── pages.css       # Page-specific styles
├── js/
│   └── app.js          # Main JavaScript
└── pages/
    ├── basics.html     # বেসিক module
    ├── intermediate.html # ইন্টারমিডিয়েট module
    ├── advanced.html   # অ্যাডভান্সড module
    ├── phd-level.html  # PhD লেভেল module
    └── playground.html # Interactive code editor
```
